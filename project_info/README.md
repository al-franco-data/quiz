# Project Information

This folder contains supporting documentation for the Quiz Master project.

Documentation is organized into three levels:

README.md
    Understand the project.

README_DETAILS.md
    Understand the decisions.

project_info/
    Understand everything else.

In general:

- Read README.md first.
- Read README_DETAILS.md if you want to understand why the project was organized and designed in a particular way.
- Explore the files in project_info/ for architecture diagrams, lessons learned, development notes, future plans, and supporting documentation.

---

## Purpose of This Folder

The purpose of this folder is to separate detailed documentation from the main project files.

Keeping documentation here allows:

- The main project folder to remain focused on active code.
- README.md to remain a project overview.
- README_DETAILS.md to remain focused on design decisions.
- Supporting documentation to grow without cluttering the main project.

---

## Suggested Reading Order

1. README.md
2. README_DETAILS.md
3. ARCHITECTURE.md
4. FUTURE_PLANS.md
5. LESSONS_LEARNED.md

Additional files may be added as the project evolves.

---

## Typical Contents

Examples of documents that may be stored here include:

- Architecture diagrams
- Mermaid diagrams
- Design decisions
- Lessons learned
- Development notes
- Future plans
- Research notes
- References
- Project history
- Testing notes

Not every project will contain all of these documents.

---

## Documentation Philosophy

Documentation should be understandable to readers at different levels of experience.

The goal is not merely to explain how to run the project. The goal is also to explain how the project is organized, why it was designed in a particular way, and how future development is expected to occur.

Concise documentation is desirable, but understanding takes priority over brevity.
